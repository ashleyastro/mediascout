    Use your media lists in Claude and ChatGPT

    MediaScout runs an MCP server. Once connected, you can ask the assistant things like "Find journalists covering HR tech in the EU and draft pitches for the top five."

    Claude

    1. Open Settings → Connectors in Claude.
    2. Choose Add custom connector and paste the URL above.
    3. Enable the connector in a chat from the tools menu.

    ChatGPT

    1. Open Settings → Apps & Connectors → Advanced and turn on Developer mode.
    2. Choose Create, name it MediaScout, and paste the URL above.
    3. Select the connector from the tools menu in a chat.

    The server must be reachable over public HTTPS for either product to connect. Set MCP_SECRET so the URL cannot be guessed.
